# HUD 使用说明

## 安装

1. Magisk → 模块 → 从本地安装 → `release/hudbridge.zip` → 重启。
2. 打开「HUDdiy」。
3. 打开「开机自动运行」，点「保存并启动」。
4. 点「授权通知访问」，在系统列表里允许「HUDdiy」。
5. 高德车机版开始导航即可。

## 日常使用

- 导航：高德开始导航后，仪表显示路名 + 剩余距离 + 转向箭头。
- 音乐：未导航时，仪表显示当前歌曲「歌名 - 歌手」。
- 导航结束：自动清屏并回到歌曲。
- 开机后模块自动拉起 HUD，不需要每次打开 App。

## 自检

App 内有两个按钮：

- 「自检：导航字段」→ 仪表出现 `HUD TEST`
- 「自检：音乐字段」→ 仪表出现 `MUSIC TEST`

如果自检也不显示，先看 `/data/data/io.github.hudfree/files/hud.log`。

## 注意

- 导航期间不显示歌名。
- 长距离（>1km）路名由 `561036824` 保持。
- 修改 priv-app 有风险，刷前备份。
